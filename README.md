# NECTA — 9necta9.github.io

Public site for **NECTA** (Seoul-based electronic pop artist).

Live: https://9necta9.github.io

## Structure
- `index.html` — main link page (bylines, music videos, streaming, contact). Self-contained: fonts and the hero photo are embedded.
- `assets/og-main.jpg` — Open Graph image for the main page (same hero photo).
- `gotta-fix-my-bangs/index.html` — EP *GOTTA FIX MY BANGS* press kit (EN / KR / ES / JP / DE / FR), at https://9necta9.github.io/gotta-fix-my-bangs/
- `assets/` — shared static files used by the EPK page: `css/`, `js/`, `audio/`, `covers/`, `photos/`, plus the EP zip, press profile zip and lyrics/credits PDF.
- `scripts/build_lyrics_pdf.py` — builds the lyrics & credits PDF.
