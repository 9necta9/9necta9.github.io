# NECTA — Official EPK

One-page electronic press kit for **NECTA** (Seoul-based electronica singer-songwriter) — built around the EP *GOTTA FIX MY BANGS*.

Live: https://9necta9.github.io

## Contents
- `index.html` — single-page EPK (EN / KR toggle, default EN)
- `assets/css/style.css` — paper & ink zine styling (hairlines, condensed/serif/mono type), mobile-first
- `assets/js/main.js` — language switch, index menu, hero slideshow, mini player bar (HTML5 audio)
- `assets/audio/` — GOTTA FIX MY BANGS (mini player source)
- `assets/NECTA-Press-Photos.zip` — six hi-res press photos
- `assets/photos/` — 6 press photos (full-res master + 1600/900 display sizes), hero and OG image
