# NECTA — Official EPK

One-page electronic press kit for **NECTA** (Seoul-based electronic / alt-pop singer-songwriter & visual director).

Live: https://9necta9.github.io

## Contents
- `index.html` — single-page EPK (EN / KR toggle, default EN)
- `assets/css/style.css` — pastel sky-blue pop styling (red viewport frame, rounded cards, pill nav), mobile-first
- `assets/js/main.js` — language switch, nav, gallery lightbox, mini player bar (HTML5 audio)
- `assets/audio/` — GOTTA FIX MY BANGS (mini player source)
- `assets/photos/` — 6 press photos (full-res master + 1600/900 display sizes), hero and OG image
- `assets/logos/` — Apple Music and Korean Music Awards marks
